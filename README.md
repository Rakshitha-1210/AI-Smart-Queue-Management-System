# AI-Powered Smart Queue & Crowd Intelligence System

## 📌 Overview
The AI-Powered Smart Queue & Crowd Intelligence System is a real-time crowd management solution that uses Artificial Intelligence and Computer Vision to monitor queues, count people, estimate waiting time, and provide smart recommendations in crowded public places.

## 🚀 Features
- Real-time people detection
- Queue counting system
- Waiting time estimation
- Queue status monitoring
- Voice announcements
- Smart counter recommendations
- Crowd management support

## ⚙️ Technologies Used
- Python
- OpenCV
- HOG + SVM
- pyttsx3
- NumPy

## 🔄 System Working
1. Webcam captures live video.
2. OpenCV detects people in the queue.
3. System counts people in real time.
4. Waiting time is calculated automatically.
5. Queue status is displayed as Normal, Busy, or Overcrowded.
6. Voice announcements provide queue updates and recommendations.
